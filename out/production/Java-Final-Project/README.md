Welcome to the Enroll Later enrollment system. The code in enroll.java can be copied into your IDE within a new or existing folder. In order to successfully run this program, you need to download the courses.csv file and put it into the same project folder that you have placed the enroll.java in. Once all that is done, you can start running the code and two new databses will be created when you run the program for the first time, which are studentinfo.csv and studentLogInDB.csv which are two files used to store all the data for your course management needs. You can choose to register a new user or login with an existing one, or exit the program. Once you're in the main menu, you have many options such as viewing the course list, viewing your own registered courses, adding or dropping a course, and logging out. These are the key features of our program and we hope you use it to the best of your abilities.
